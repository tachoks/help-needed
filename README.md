# XEON OS PHOENIX

An ambitious Android-based operating system project

XEON OS is a custom Android-based operating system built on the Android Open Source Project (AOSP).

Our vision
- Custom gaming-inspired interface
- Neon RGB design
- Redesigned Android experience
- Custom system applications
- Android app compatibility

Looking for contributors

We're interested in connecting with people who enjoy:
- AOSP and Android development
- Kotlin and Java
- Linux kernel development
- UI/UX design
- Software testing

 Project status

Version: 1.0 PHOENIX  
*Status: Pre-Alpha  
Foundation: AOSP

This is currently an unpaid, volunteer open-source project. Contributions are welcome!
